Thank you for choosing FlintmanCMS.

Install:
    You will need:
        php 5.0 or greater
        mysql 4.0 or greater


Upload all files to your server.  You will need write permission on
'/admin/config.php' and '/templates_c'.  Once files and permission is set
go to the root folder of flintmanCMS (ex. www.yoursite.com).  The install will
start. Note: you will need to have the database created in order to install.
 Follow the steps and flintmanCMS will install itself.  Once completed delete
the install folder and click the link.  There will be an admin link at the
botton in order to log in.  At this point you have installed flintmanCMS
