FORM PROCESSING PATTERN:
------------------------
if ($action == 'add') {
    if (!isset($_POST['submit'])) {
        // Display form
        $form_action = "admin.php?n=plugins&p=pluginname&action=add";
        $content = '<input type="text" name="field" class="form-control">';
        $content .= '<input type="submit" name="submit" value="Save">';
    } else {
        // IMPORTANT: Verify CSRF token FIRST!
        if (!isset($_POST['csrf_token']) || !verify_csrf_token($_POST['csrf_token'])) {
            die("CSRF token validation failed");
        }
        // Process form
        $value = scrub_input($_POST['field']);
        // Save to database
        header("Location: admin.php?n=plugins&p=pluginname");
        exit;
    }
}

FILE STRUCTURE:
==============

IMPORTANT: FlintmanCMS uses "flintmancms" as the DB_PREFIX
- In variable.php: List tables WITHOUT prefix (e.g., "pluginname_table")
- In install.sql: Use FULL names WITH prefix (e.g., flintmancms_pluginname_table)

COMMON PITFALLS TO AVOID:
=========================

SQL INJECTION:
❌ Direct SQL concatenation: "SELECT * FROM table WHERE id=" . $_GET['id']
✅ Use quote_smart: sprintf("... WHERE id=%s", quote_smart($id))

❌ String concatenation: "... WHERE name='" . $_POST['name'] . "'"
✅ Always quote_smart: sprintf("... WHERE name=%s", quote_smart($name))

Advanced (optional for new code):
✅ Prepared statements: $db->sql_prepare("SELECT * FROM table WHERE id = ?", [$id])

XSS (Cross-Site Scripting):
❌ Direct output: $body .= '<div>' . $data['name'] . '</div>'
✅ Escape output: $body .= '<div>' . htmlspecialchars($data['name'], ENT_QUOTES, 'UTF-8') . '</div>'

❌ Unescaped attributes: '<img alt="' . $_GET['title'] . '">'
✅ Escaped: '<img alt="' . htmlspecialchars($_GET['title'], ENT_QUOTES, 'UTF-8') . '">'

CSRF PROTECTION:
❌ Missing token: Form without csrf_token field
✅ Include token: <input type="hidden" name="csrf_token" value="{$csrf_token}">

❌ No verification: Processing POST without checking token
✅ Verify first: if (!verify_csrf_token($_POST['csrf_token'])) die("CSRF failed");

FILE UPLOADS:
❌ Trust extensions: if ($_FILES['file']['type'] == 'image/jpeg')
✅ Use validator: $validation = validate_upload($_FILES['file'], ['image/jpeg'])

❌ User filenames: move_uploaded_file($tmp, 'uploads/' . $_FILES['file']['name'])
✅ Random names: move_uploaded_file($tmp, 'uploads/' . $validation['filename'])
