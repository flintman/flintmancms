# Getting Started

Welcome to **FlintmanCMS**! If you're seeing this, you've successfully logged into the admin panel. This guide will help you navigate and manage your content management system.

---

## 📄 Pages Admin

The **Pages Admin** section allows you to manage all pages on your website.

### Accessing Pages
1. Click **Pages Admin** in the menu
2. You'll see a list of all pages with options to:
   - **Edit** - Modify page content
   - **Delete** - Remove pages permanently

### Editing Pages
When editing a page, you can:
- ✅ **Activate/Deactivate** the page
- ✅ **Edit the page title**
- ✅ **Show/hide the title** on the page
- ✅ **Edit content** using the WYSIWYG editor

### WYSIWYG Editor
The content editor is a "What You See Is What You Get" editor that makes formatting easy.

**Want to edit HTML directly?**
- Click the **"Add/Remove Editor"** link below the editor
- This switches to a plain text box for HTML code entry
- Click again to return to the visual editor

## 📊 Logs

The **Logs** section helps you monitor security and system events.

### What You'll See
- 🛡️ **Security events** - Failed login attempts, potential attacks
- 📝 **System logs** - Important system activities

### Managing Logs
- Review logs regularly to monitor site security
- Delete old logs if the list becomes too large
- Keep recent logs for security tracking

> **Tip:** Frequent hack attempts from the same IP may indicate a security threat. Consider implementing IP blocking or rate limiting.

## ⚙️ Configure

Hover over the **Configure** link to access system configuration options:

### Site Info
- Edit site title and description
- Configure site-wide settings
- Set template/theme preferences
- Choose language settings

### Users Management
- Add new admin users
- Edit existing user accounts
- Manage user permissions
- Reset user passwords

### Menu Links
- Add custom menu items
- Edit existing links
- Reorder menu items
- Delete unwanted links

### Groups Management
- Create user groups
- Assign permissions to groups
- Organize users by role

### Email Configuration
- Set up email notifications
- Configure SMTP settings
- Receive alerts for system issues
- Get notifications for important events

## 🔌 Plugins Admin

The **Plugins** section allows you to extend FlintmanCMS with custom functionality.

### What Are Plugins?
Plugins are add-on modules that enhance your CMS with additional features:
- Photo galleries
- Contact forms
- E-commerce features
- Custom content types
- And more!

### Managing Plugins
- **View** all installed plugins
- **Activate/Deactivate** plugins
- **Configure** plugin settings
- **Install** new plugins

### Available Plugins
- **Hello World** - Example plugin for developers
- **Portfolio** - Showcase your work with galleries

> **For Developers:** You can create custom plugins to add any functionality to your CMS. Check the plugin development documentation for details.
