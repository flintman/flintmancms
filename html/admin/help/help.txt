

If you are seeing this then you know how to log in.  This is the first step.  I
have tried to make this program as easy as possible to navigate and to setup.
I have written this to hopefully give some direction on what to do.


Pages Admin:
    You see a link called Pages Admin in the menu.  This allow you to edit, add,
and delete pages on your site.  If you click this link it will open up a list
of all the pages you have setup.  You can click edit to edit that page or delete
if you want to get rid of it.  If you click edit you will be able to deactivate
or activate the page, edit the title, to able to deactivate or activate showing
the title on the page, and be able to edit the content of the page.  The content
of the page is displayed in an editor which is a what you see is what you get.
You will also see an 'add/remove editor' link below that.  If you wanted to add
just html code you can do this by removing clicking that link and it will replace
the nice editor with a blank box.

Logs:
    This link will bring you into the logs section which will display any hack
attempts on your site.  If there are to many you can delete them but it's good
to keep them up to keep track of them.

Configure:
    When you scroll over this link you will see another menu pop up.  Here you
can edit the site info, add and edit users, add and edit menu links, add and edit
groups, and setup email to email out any issues that pop up.

Plugins admin:
    This is where addon or plugins are added and edit on the site.  This can be
any custom program that you wanted to add to this content management system.
